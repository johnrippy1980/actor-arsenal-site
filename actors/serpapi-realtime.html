Overview

This actor provides instant, real-time Google SERP snapshots powered by SERPApi. See exactly what appears on the search results page including organic results, local pack, featured snippets, People Also Ask, and more.

Features

  • Real-Time Results: Get current SERP state instantly
  • Rich Result Extraction: Capture featured snippets, local pack, PAA, knowledge panels
  • Location Targeting: Get results for any city, state, or country
  • Device Selection: Desktop or mobile SERPs
  • Multiple Engines: Google, Bing, Yahoo, DuckDuckGo
  • Image Results: Extract Google Images results
  • News Results: Extract Google News results
  • BYOK Pattern: Bring your own SERPApi key

Input Parameters

Example Usage

Basic SERP Snapshot

{

"query": "best marketing agency",


"location": "New York, NY",


"device": "desktop",


"serpApiKey": "your-serpapi-key"


}

Mobile SERP with Local Pack

{

"query": "plumber near me",


"location": "Miami, FL",


"device": "mobile",


"num": 20,


"serpApiKey": "your-serpapi-key"


}

Image Search

{

"query": "modern office design",


"resultType": "images",


"num": 50,


"serpApiKey": "your-serpapi-key"


}
