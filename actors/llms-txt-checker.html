Batch check websites for llms.txt files and identify AI optimization opportunities. Similar to how robots.txt guides search engine crawlers, llms.txt provides instructions to Large Language Models.

What is llms.txt?

The llms.txt file is an emerging standard that websites use to communicate with AI systems. It helps LLMs understand:

  • What the site/company does
  • How to present information about the business
  • Contact information and key pages
  • Brand guidelines and preferences

Features

  • Batch URL Processing: Check hundreds of URLs in a single run
  • Full Spec Support: Checks both /llms.txt and /llms-full.txt
  • Content Analysis: Parses file structure, sections, and metadata
  • AI Recommendations: Get suggestions for improving existing llms.txt files
  • Sales Opportunity Identification: Find prospects missing AI optimization
  • Webhook Integration: Send results to your CRM or automation tools

Use Cases

Lead Generation

Scan competitor customer lists or industry directories to find businesses without llms.txt files - perfect prospects for AI optimization services.

SEO Audits

Include llms.txt analysis in your technical SEO audits to identify AI readiness gaps.

Competitive Analysis

See how competitors are presenting themselves to AI systems.

Output

Each result includes:

  • url: The website checked
  • hasLlmsTxt: Whether /llms.txt exists
  • hasLlmsFullTxt: Whether /llms-full.txt exists
  • fileSize: Size of the llms.txt file
  • content: Raw file content
  • sections: Parsed sections from the file
  • recommendations: AI-generated improvement suggestions
  • salesOpportunity: Rating (HIGH/MEDIUM/LOW/NONE) for sales potential
