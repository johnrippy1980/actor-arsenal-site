Extract product data, pricing, sales metrics, reviews, and seller information from TikTok Shop. Built for e-commerce research, competitor analysis, dropshipping discovery, and market intelligence.

  • E-commerce Entrepreneurs - Discover trending products and validate product ideas before investing

Key Features

Data Extraction

  • Product Details - Title, price, original price, discount percentage, currency
  • Sales Metrics - Sold count, rating, review count
  • Seller Information - Shop name, shop URL, verified status
  • Product Tags - Best Seller, Official Store, New, Trending, Flash Sale badges

Scraping Methods

  • Category Browsing (Recommended) - Click-based navigation through TikTok Shop categories
  • Search Queries - Keyword-based product discovery
  • Direct Product URLs - Scrape specific product pages
  • Shop/Seller URLs - Extract all products from a seller's store

Anti-Detection Technology

  • Camoufox Integration - Browser fingerprint randomization
  • Mobile Safari Emulation - iPhone user agent for higher success rates
  • Residential Proxy Support - Bypass TikTok's datacenter IP blocks
  • Smart Rate Limiting - Automatic delays and retry logic

Advanced Features

  • Multi-Region Support - 12 regions with automatic currency handling
  • FAST Extraction Mode - Scrapes from listing pages without slow individual page loads
  • Infinite Scroll Support - Automatically loads more products for large scrapes
  • Fallback Strategies - Multiple extraction methods ensure data collection
  • AI Sentiment Analysis - Optional review/comment sentiment scoring

Limitations & Constraints

Per-Run Limits

  • Max Products: 500 per run (use multiple runs for larger datasets)
  • Max Reviews: 50 per product
  • Max Comments: 100 per product
  • Timeout: 5 minutes per run (300 seconds)

Technical Limitations

  • Images: TikTok lazy-loads images; listing pages may not include all product images
  • Real-time Pricing: Prices reflect scrape time; flash sales may change rapidly
  • Regional Restrictions: Some products only available in specific regions
  • Anti-Bot Detection: TikTok actively blocks scrapers; success rates vary

Success Rate Factors

  • Best: Category browsing (clickCategories) with Mobile Safari + Camoufox + Residential Proxy
  • Good: Search queries with anti-detection enabled
  • Variable: Direct product URLs (may trigger CAPTCHA)
  • Challenging: High-volume scrapes (500+ products) or rapid successive runs

Fallback Strategies

The scraper uses multiple extraction methods to maximize success:

  1. FAST Extraction (Primary) - Extracts data directly from category/search listing pages without loading individual product pages. Much faster and more reliable.
  2. JSON State Extraction - Parses TikTok's embedded SIGI_STATE JSON data when available.
  3. DOM Extraction - Falls back to parsing HTML elements when JSON is unavailable.
  4. Firecrawl API (Optional) - Use external API if browser-based methods fail.
  5. Click Fallback - If direct navigation fails, falls back to click-based navigation.

Best Practices

For Highest Success Rates

  1. Use Category Browsing - clickCategories has better success than search
  2. Enable All Anti-Detection - Keep useCamoufox and useMobileSafari enabled
  3. Use Residential Proxies - TikTok blocks most datacenter IPs
  4. Start Small - Test with 10-20 products before scaling up
  5. Try Southeast Asian Regions - ID, MY, TH often have higher success rates

For Cost Optimization

  1. Skip Reviews - Only enable includeReviews when needed
  2. Use FAST Extraction - Default mode, no need to change
  3. Batch by Category - Run separate jobs per category for better organization
  4. Monitor Success - Check logs for extraction method used

Frequently Asked Questions

Why are some products returning empty data?

TikTok Shop uses aggressive anti-bot detection. Try:

  • Enabling useMobileSafari (emulates iPhone)
  • Ensuring useCamoufox is enabled
  • Using residential proxies (not datacenter)
  • Trying a different region (ID, MY, TH often work better)
  • Running during off-peak hours

Why don't I see product images?

TikTok lazy-loads images in their SPA. The FAST extraction mode extracts from listing pages where images may not be fully loaded. For full image URLs, you may need to scrape individual product pages (slower but more complete).

How do I scrape more than 500 products?

Run multiple jobs with different categories or search terms. The 500 limit is per run to ensure reliability and prevent timeouts.

Why did my run return "NO_PRODUCTS_FOUND"?

This usually means TikTok's anti-bot measures blocked the scrape. Solutions:

  1. Enable Demo Mode first to verify your setup
  2. Use category browsing instead of search
  3. Try a different region
  4. Check that residential proxy is configured

Is this against TikTok's Terms of Service?

This scraper is intended for legitimate business research purposes. Users are responsible for ensuring compliance with TikTok's Terms of Service and applicable laws. We recommend reviewing TikTok's policies before use.

How often does TikTok update their anti-bot measures?

TikTok frequently updates their detection systems. We continuously update this scraper to maintain reliability. If you experience issues, try again later or contact support.

Common Problems & Solutions

"Invalid API key" error

Cause: Your AI provider API key is wrong, expired, or doesn't have the right permissions.
Fix: Double-check your API key. Make sure you copied it exactly without extra spaces.

"Rate limit exceeded" error

Cause: You've hit TikTok's rate limits or the AI provider's limits.
Fix: Wait a few minutes, then try again. Consider reducing maxProducts or running during off-peak hours.

Empty or incomplete results

Cause: TikTok may have anti-scraping protection active.
Fix:

  • Enable useCamoufox and useMobileSafari
  • Use residential proxies
  • Try a different region (ID, MY, TH)

Demo data showing instead of real results

Cause: demoMode is still set to true.
Fix: Set demoMode: false and ensure proxy is configured.
