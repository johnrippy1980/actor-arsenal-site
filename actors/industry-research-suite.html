Data Sources

Features

  • Multi-Source Aggregation: Combine data from 5+ authoritative sources
  • AI-Powered Summaries: Executive summaries using Claude, GPT-4, or Gemini (BYOK)
  • NAICS Classification: Target specific industries using official classification codes
  • Geographic Focus: National, state, or city-level research
  • Trend Analysis: Historical data and future projections
  • Competitive Intelligence: Market size, growth rates, key players

Getting Started

Free Sources (No API Key Required)

1. Google Trends: Automatically included

2. Census Bureau: Uses public API endpoints

3. SBA.gov: Uses public developer API

Premium Sources (BYOK)

#### IBISWorld API

1. Go to IBISWorld API Access

2. Contact sales for API credentials

3. Enter your API key in the actor input

#### Statista API

1. Visit Statista Accounts

2. Subscribe to a plan with API access

3. Generate API key in your account settings

  • County Business Patterns: Establishment counts, employment, payroll

  • Small Business Profiles: State-by-state statistics
