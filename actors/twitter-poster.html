Automate posting to Twitter/X! Create tweets, replies, and threads.

Features

  • Single Tweets - Post text updates
  • Threads - Create multi-tweet threads
  • Replies - Reply to specific tweets
  • Images - Attach photos (coming soon)

Authentication

Two options:

1. Username/Password - Works for accounts without 2FA

2. Cookies - Export cookies from logged-in session (recommended)

Example Input

Single Tweet

{

"cookies": "[{...exported cookies...}]",


"tweet": "Just discovered an amazing local pizza place! 🍕 #LocalBusiness #Foodie"


}

Thread

{

"cookies": "[{...}]",


"isThread": true,


"threadTweets": [


"🧵 5 Tips for Local SEO Success",


"1. Claim your Google Business Profile and keep it updated",


"2. Get reviews - ask happy customers!",


"3. Post regularly to your GBP",


"4. Build local citations",


"5. Create local content on your website"


]


}

Reply

{

"cookies": "[{...}]",


"replyToUrl": "https://x.com/user/status/123456789",


"tweet": "Great point! We've seen similar results with our clients."


}

Output

{

"success": true,


"tweetUrl": "https://x.com/yourhandle/status/..."


}
