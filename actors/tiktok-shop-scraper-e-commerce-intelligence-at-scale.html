Scrape TikTok Shop for product data, prices, reviews, seller info, and sales metrics. Perfect for e-commerce research, competitor analysis, dropshipping product discovery, and market intelligence.

Key Features

  • Multi-Region Support - Scrape TikTok Shop across 12 regions with proper currency formatting
  • Product Search - Search by keywords to discover trending products
  • Direct Product Scraping - Scrape specific product URLs for detailed data
  • Shop/Seller Scraping - Extract all products from a seller's store
  • Review Collection - Optional review scraping with ratings, content, and verification status
  • Anti-Detection - Camoufox browser support for avoiding blocks
  • Firecrawl Integration - Optional API-based scraping for reliability
  • Webhook Support - Send results to Zapier, Make, n8n, or custom endpoints

Quick Start - Real Scraping

To scrape real TikTok Shop data, use this configuration:

{

"searchQueries": ["shampoo", "skincare"], "maxProducts": 50, "region": "DE", "demoMode": false }

Important: Set demoMode: false to scrape actual TikTok Shop data. Demo mode generates sample data for testing without charges.

{

{

{

Example 5: Demo Mode for Testing

{

"searchQueries": ["shampoo"], "maxProducts": 10, "region": "DE", "demoMode": true }

Anti-Detection Options

Camoufox Mode

Camoufox is an anti-fingerprinting browser. When enabled:

  • Randomizes browser fingerprints
  • Hides automation indicators
  • Mimics human browsing patterns
  • Evades common bot detection
Enable with "useCamoufox": true.

Firecrawl Mode

Firecrawl provides reliable web scraping via API:

  • Handles JavaScript rendering
  • Built-in proxy rotation
  • Automatic retries
  • No browser management needed
Enable with "useFirecrawl": true and provide your API key.

Troubleshooting

No products found

  • Ensure demoMode is set to false
  • Try enabling useCamoufox for anti-detection
  • Use Apify proxy (proxyConfiguration.useApifyProxy: true)
  • Try different search queries or regions

Wrong currency/format

  • Check the region parameter matches your target market
  • German (DE) uses € after the price with comma decimal: 24,99 €
  • US uses $ before the price with period decimal: $24.99

Getting blocked

  • Enable useCamoufox: true
  • Enable Apify proxy
  • Try useFirecrawl with API key
  • Reduce maxProducts and add delays between runs
