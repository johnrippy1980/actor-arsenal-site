Federal Contract Opportunities - Search SAM.gov by NAICS, Agency & Set-Aside

Search SAM.gov for federal contract opportunities, solicitations, and awards. Find government contracts by NAICS code, set-aside type, agency, location, and keywords. Perfect for government contractors, business development teams, and procurement intelligence.

Features

  • Search Contract Opportunities: Find active federal contract opportunities with advanced filters
  • NAICS Code Search: Search by North American Industry Classification System codes
  • Set-Aside Filtering: Filter by small business set-asides (8(a), SDVOSB, WOSB, HUBZone, etc.)
  • Agency Search: Find opportunities from specific federal agencies
  • Award Tracking: Track contract awards and winners
  • Solicitation Monitoring: Monitor solicitations and RFPs
  • Demo Mode: Test without API credentials using realistic sample data

Input Parameters

Task Selection

  • task: Operation to perform
- search_opportunities - Search all contract opportunities

- get_opportunity - Get specific opportunity by ID

- search_by_naics - Search by NAICS code

- search_by_agency - Search by federal agency

- search_by_set_aside - Search by set-aside type

- search_awards - Search contract awards

- search_solicitations - Search active solicitations

Authentication

  • apiKey: Your SAM.gov API key (get free at sam.gov)
  • demoMode: Run with sample data (no API key required)

Search Filters

  • postedFrom / postedTo: Date range (MM/dd/yyyy format)
  • naicsCode: Industry classification code (up to 6 digits)
  • classificationCode: Product/service code
  • typeOfSetAside: Small business set-aside type
  • procurementType: Notice type (solicitation, award, sources sought, etc.)
  • organizationCode / organizationName: Federal agency
  • state / zip: Place of performance location
  • title: Keyword search in opportunity titles
  • status: active, inactive, archived, or cancelled

Pagination

  • limit: Records per request (max 1000)
  • offset: Page offset for pagination

Webhook Delivery

  • webhookUrl: Send results to Zapier, Make, n8n, or custom endpoints

API Rate Limits

SAM.gov API has the following limits:

  • 1,000 requests per day for registered API keys
  • Maximum 1,000 records per request
  • Date range searches required for most endpoints

Getting Your API Key

1. Create an account at SAM.gov

2. Go to your profile settings

3. Navigate to "Public API Key"

4. Generate and copy your API key

5. Use it in the apiKey input field
