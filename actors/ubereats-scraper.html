Scrape Uber Eats for restaurant listings, menus, prices, ratings, and delivery information. Perfect for food delivery market research, competitor analysis, and restaurant discovery.

Features

  • Restaurant Search - Search by cuisine, restaurant name, or food type
  • Menu Extraction - Get full menu items with prices and descriptions
  • Ratings & Reviews - Extract ratings and review counts
  • Delivery Info - Delivery fees, time estimates, and Uber One eligibility
  • Multi-Cuisine Support - Filter by 13+ cuisine types
  • Demo Mode - Test with sample data before scraping

Quick Start (Demo Mode)

Run the actor with default settings to see sample restaurant data:

{

"demoMode": true,


"searchTerm": "pizza",


"location": "San Francisco, CA",


"cuisineType": "all",


"maxResults": 20


}

Search for Restaurants

{

"demoMode": false,


"scrapeType": "search",


"searchTerm": "sushi",


"location": "New York, NY",


"cuisineType": "japanese",


"maxResults": 50,


"includeMenu": true


}

Scrape Specific Restaurant

{

"demoMode": false,


"scrapeType": "store_profile",


"storeUrl": "https://www.ubereats.com/store/restaurant-name",


"includeMenu": true


}

Input Parameters

Cuisine Types

  • all - All cuisines
  • american - American food
  • chinese - Chinese cuisine
  • mexican - Mexican food
  • italian - Italian cuisine
  • japanese - Japanese/Sushi
  • indian - Indian cuisine
  • thai - Thai food
  • fast_food - Fast food
  • pizza - Pizza places
  • burgers - Burger joints
  • healthy - Healthy options
  • breakfast - Breakfast/Brunch

Pro Tips

1. Start in Demo Mode - Test your configuration before actual scraping

2. Use Specific Searches - Narrow searches produce more relevant results

3. Include Menu Data - Set includeMenu: true for full restaurant profiles

4. Respect Rate Limits - Keep maxResults reasonable for stable operation

5. Combine with Other Scrapers - Use with DoorDash and Grubhub scrapers for complete market coverage
