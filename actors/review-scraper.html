Input Options

Required

  • businessName - Name of the business
  • location - City, State or address

Platform URLs (Optional)

Provide direct URLs for faster, more accurate scraping:

  • googleMapsUrl - Google Maps business URL
  • yelpUrl - Yelp business page URL
  • facebookUrl - Facebook page URL (required for FB)
  • bbbUrl - BBB profile URL
  • tripAdvisorUrl - TripAdvisor URL
  • healthgradesUrl - Healthgrades provider profile URL (NEW)
  • avvoUrl - Avvo attorney profile URL (NEW)
  • opentableUrl - OpenTable restaurant URL (NEW)

Configuration

  • platforms - Which platforms to scrape
  • maxReviewsPerPlatform - Limit reviews per platform
  • includeResponses - Include owner responses
  • minRating / maxRating - Filter by rating
  • sortBy - Sort results
  • outputFormat - Combined or by platform

BYOK (Bring Your Own Keys)

  • serpApiKey - Enhanced Google scraping
  • yelpApiKey - Official Yelp Fusion API

Output

Dataset

Combined review data with:

  • Reviewer name and avatar
  • Rating and review text
  • Date posted
  • Owner response (if available)
  • Platform identification

Key-Value Store

  • REVIEW_REPORT - Complete aggregated report
  • SENTIMENT_REPORT - Sentiment analysis with recommendations

Best Practices

1. Provide Direct URLs when possible for more accurate results

2. Run Regularly to catch new reviews quickly

3. Focus on Negatives - Set maxRating: 3 to find issues fast

4. Track Response Rate - Aim for 100% response rate

Limitations

  • Some platforms require authentication for full data
  • Review counts may vary from platform totals
  • Rate limiting may affect large scrapes
