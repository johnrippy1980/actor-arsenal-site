Automate posting pins to Pinterest! Create pins with images, descriptions, and links.

Features

  • Create Pins - Post images with titles and descriptions
  • Board Selection - Choose which board to pin to
  • Destination Links - Add clickable links to your pins
  • Alt Text - Include accessibility descriptions

Authentication

Two options:

1. Email/Password - Works for accounts without 2FA

2. Cookies - Export cookies from logged-in session (recommended)

Example Input

Basic Pin

{

"cookies": "[{...exported cookies...}]",


"pinTitle": "Beautiful Sunset Photography",


"pinDescription": "Captured this amazing sunset at the beach! Perfect for nature lovers. #sunset #photography #nature",


"imageUrl": "https://example.com/sunset.jpg",


"destinationLink": "https://mywebsite.com/gallery",


"boardName": "Nature Photography"


}

Business Pin

{

"cookies": "[{...}]",


"pinTitle": "5 Tips for Local SEO Success",


"pinDescription": "Learn how to improve your local search rankings with these proven strategies. Click to read the full guide!",


"imageUrl": "https://example.com/seo-infographic.png",


"destinationLink": "https://myblog.com/local-seo-tips",


"boardName": "Marketing Tips",


"altText": "Infographic showing 5 local SEO tips"


}

Output

{

"success": true,


"pinUrl": "https://pinterest.com/pin/...",


"boardUsed": "Marketing Tips"


}

Tips

  • Use high-quality vertical images (2:3 ratio works best)
  • Include relevant keywords in title and description
  • Add hashtags for better discoverability
  • Use destination links to drive traffic
