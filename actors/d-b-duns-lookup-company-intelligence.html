API Integration

This actor connects to an external API service. You'll need valid API credentials from the service provider.

Access D&B Direct+ API for company search, DUNS number lookup, firmographics, credit scores, risk ratings, beneficial ownership, corporate linkage, and business verification. Essential for B2B sales, credit decisions, supplier risk, and KYC compliance.

Features

  • Company Search & Match: Find companies and resolve to DUNS numbers
  • Firmographics: Employee count, revenue, industry codes, locations
  • Credit Scores: Commercial credit scores and payment predictions
  • Risk Ratings: Viability ratings, financial stress scores, failure predictors
  • Beneficial Ownership: Ultimate parent, ownership chains, UBO data
  • Corporate Linkage: Parent/subsidiary relationships, family trees
  • Public Records: Liens, judgments, suits, UCC filings, bankruptcies
  • KYC Compliance: Know Your Customer and business verification data
  • Demo Mode: Test with realistic sample data (no credentials required)

Input Parameters

Task Selection

  • task: Operation to perform
- search_company - Search companies by name/location - match_company - Match company to DUNS number - get_company_profile - Detailed company profile - get_firmographics - Company size, revenue, industry - get_credit_score - Commercial credit score - get_risk_rating - Viability and risk assessment - get_financial_stress - Financial stress score - get_payment_info - Payment history and trends - get_beneficial_ownership - Ownership structure - get_corporate_linkage - Parent/subsidiary tree - get_public_records - Liens, judgments, suits - get_contacts - Executive contacts - find_competitors - Similar companies - kyc_compliance - KYC/AML verification - batch_match - Batch DUNS matching

Authentication

  • username: D&B Direct API username
  • password: D&B Direct API password
  • demoMode: Run with sample data (no credentials required)

Company Identification

  • dunsNumber: 9-digit D-U-N-S number
  • companyName: Company name for search
  • countryCode: ISO country code (US, GB, DE, etc.)
  • state: State or province
  • city: City name
  • postalCode: ZIP/postal code
  • streetAddress: Street address
  • telephoneNumber: Phone number
  • registrationNumber: Business registration (EIN, etc.)

Industry Filters

  • naicsCode: NAICS industry code
  • sicCode: SIC industry code

Match Settings

  • matchType: Basic or Advanced matching
  • confidenceLowerLimit: Minimum confidence (1-10)
  • maxCandidates: Max results to return

Product Selection

  • productCode: D&B data product
- DCP_STD - Standard Company Profile - DCP_ENH - Enhanced Company Profile - DCP_PREM - Premium Company Profile - BIR - Business Information Report - COMPR - Comprehensive Report - CPTR - Compact Report - BBR - Business Background Report

Common Problems & Solutions

"Invalid API key" error

Cause: Your API key is wrong, expired, or doesn't have the right permissions. Fix: Double-check your API key. Make sure you copied it exactly without extra spaces.

"Rate limit exceeded" error

Cause: You've hit the API's rate limits. Fix: Wait a few minutes, then try again. Consider reducing the number of concurrent requests.

Empty or incomplete results

Cause: The target may have anti-scraping protection or the data doesn't exist. Fix:

  • Check if the URL/search query is correct
  • Try with different parameters
  • Some sites may block automated access

Demo data showing instead of real results

Cause: demoMode is still set to true. Fix: Set demoMode: false and provide your API key(s).
