Yellow Pages Scraper

Scrape business listings from Yellow Pages. Extract phone numbers, addresses, websites, hours, reviews, and more for any category and location. Features: - Business name and contact info - Phone numbers and addresses - Website URLs - Business hours - Customer reviews and ratings - Category and service tags - Email extraction (when available) Ideal for: - Lead generation - Market research - Competitor analysis - Local business directories. Built by John Rippy (https://www.linkedin.com/in/johnrippy/ | https://johnrippy.link/).

Features

  • Category Search: Search by any business category (plumber, restaurant, dentist, etc.)
  • Location Targeting: Search by city/state or ZIP code
  • Comprehensive Data: Phone, address, website, hours, rating, reviews
  • Smart Filtering: Filter by rating, website presence, phone availability
  • Review Extraction: Optionally scrape review snippets
  • Export Ready: Clean data ready for CRM import or outreach

Quick Start

{
  "url": "https://example.com",
  "maxResults": 100
}

Demo Mode

Set demoMode: true to test with sample data (no charges). When you're ready for real results, set demoMode: false or omit it.

{
  "demoMode": true,
  ...
}

Input Parameters

| Parameter | Type | Description | |-----------|------|-------------| | searchQuery | string | Business category or keyword (e.g., "plumber") | | location | string | City/state or ZIP code (e.g., "Miami, FL") | | maxResults | number | Maximum businesses to scrape (default: 100) | | includeReviews | boolean | Extract review snippets (default: false) | | includeHours | boolean | Extract business hours (default: true) | | includeCategories | boolean | Extract all categories (default: true) | | minRating | number | Minimum rating filter 0-5 (default: 0) | | hasWebsite | boolean | Only businesses with websites (default: false) | | hasPhone | boolean | Only businesses with phone (default: false) | | proxyConfiguration | object | Proxy settings | | demoMode | boolean | Return sample data for testing |
