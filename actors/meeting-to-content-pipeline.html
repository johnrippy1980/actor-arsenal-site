Transform meeting transcripts from Fireflies.ai or Granola into ready-to-post social media content. Extract insights, generate LinkedIn posts, create quote cards, and optionally auto-publish.

The Problem

You have meetings full of valuable insights, but turning them into content is time-consuming:

1. Review transcript

2. Find quotable moments

3. Write posts for different platforms

4. Create graphics

5. Schedule and publish

This actor automates the entire pipeline.

Features

  • Transcript Integration: Connect to Fireflies.ai or paste transcripts directly
  • AI Insight Extraction: Find key quotes, decisions, and learnings
  • Multi-Platform Posts: Generate content for LinkedIn, Twitter/X
  • Content Styles: Professional, casual, thought leader, storytelling
  • Image Generation: Create quote cards (Canva integration)
  • Auto-Publishing: Post directly to social channels

Use Cases

  • Turn strategy meetings into thought leadership content
  • Create weekly content from client calls
  • Build personal brand from work conversations
  • Share learnings from team retrospectives
  • Document company culture through meeting highlights

Getting Your API Keys

2. Find API section

3. Generate API key

AI Providers

  • Claude: console.anthropic.com > API Keys
  • OpenAI: platform.openai.com > API Keys
  • Gemini: aistudio.google.com > Get API Key

Example Workflow

1. Meeting recorded in Fireflies.ai

2. Actor pulls transcript automatically

3. AI extracts key insights and quotes

4. Generates 3 LinkedIn posts per meeting

5. Creates quote card images

6. Posts are ready for review or auto-publishing

Tips for Best Results

  • Longer meetings (30+ min) yield more content
  • Meetings with back-and-forth discussion work better than presentations
  • Include speaker names in transcripts for attribution
  • Review and personalize generated content before publishing
