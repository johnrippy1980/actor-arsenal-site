Scrape Healthgrades for doctor profiles, patient reviews, ratings, and practice information. Essential for healthcare reputation monitoring and provider research.

Why Healthgrades Data is Valuable

Healthgrades is a leading healthcare provider review platform:

  • Patient Reviews: Verified reviews from actual patients
  • Provider Ratings: Overall ratings and category-specific scores
  • Credentials: Education, certifications, board certifications
  • Insurance: Insurance networks accepted
  • Practice Details: Office locations, hours, telehealth availability
  • Specialties: Detailed specialty and condition information

Features

  • Provider Profile Scraping: Complete doctor/provider profiles
  • Search by Specialty: Find cardiologists, dentists, dermatologists, etc.
  • Location-Based Search: Search by city, state, or ZIP code
  • Review Extraction: Patient reviews with ratings and dates
  • Insurance Filtering: Filter by accepted insurance
  • Credentials Data: Education, board certifications, awards

Use Cases

  • Healthcare Reputation Monitoring: Track reviews for your practice
  • Competitive Analysis: Compare ratings across competing providers
  • Provider Research: Research doctors before partnerships
  • Patient Acquisition: Identify areas with provider gaps
  • Market Analysis: Analyze healthcare provider density by region
  • Insurance Network Mapping: Map which providers accept specific insurance

Example Usage

Search for Cardiologists in Houston

{

"scrapeType": "search",


"specialty": "Cardiologist",


"location": "Houston, TX",


"minRating": 4.0,


"maxResults": 50


}

Scrape Single Provider Profile

{

"scrapeType": "provider_profile",


"providerUrl": "https://www.healthgrades.com/physician/dr-john-smith-abc123",


"includeReviews": true,


"maxReviewsPerProvider": 50


}

Find Dentists Accepting Blue Cross

{

"scrapeType": "search",


"specialty": "Dentist",


"location": "Chicago, IL",


"insuranceAccepted": "Blue Cross",


"acceptingNewPatients": true


}

Pricing

This actor uses pay-per-event pricing:

Example costs:
  • 50 providers with 25 reviews each: $0.10 + (50 × $0.08) + (1250 × $0.005) = $10.35
  • 100 providers, no reviews: $0.10 + (100 × $0.08) = $8.10

Rate Limiting & Best Practices

  • Built-in delays to respect Healthgrades servers
  • Residential proxy recommended for reliability
  • Maximum 500 providers per run
  • Reviews limited per provider to prevent excessive requests

Legal Considerations

  • Use data for legitimate healthcare research purposes
  • Comply with Healthgrades Terms of Service
  • Do not use for fake reviews or spam
  • Respect patient privacy in review data
  • Check HIPAA compliance for your use case
