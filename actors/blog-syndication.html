Automatically syndicate your blog posts to social media channels with AI-generated summaries tailored to each platform.

Features

  • RSS/Sitemap Monitoring: Auto-detects RSS feeds or parses sitemaps to find new blog posts
  • AI-Powered Summaries: Uses your preferred AI (OpenAI, Claude, or Gemini) to create engaging platform-specific content
  • Multi-Platform Support: Twitter/X, LinkedIn, Facebook, Instagram, Pinterest, Reddit, Google Business Profile
  • Smart Deduplication: Tracks processed posts to avoid reposting
  • UTM Tracking: Automatic UTM parameters for tracking social traffic
  • Customizable Style: Professional, casual, witty, informative, or promotional tone
  • Webhook Integration: Send results to Zapier, Make, n8n, or Slack

How It Works

1. Monitor: Actor checks your blog's RSS feed or sitemap for new posts

2. Summarize: AI generates platform-optimized summaries with hashtags

3. Post: Content is syndicated to selected social platforms

4. Track: Results are logged and webhooks triggered

Input Configuration

Required

  • blogUrl: URL of your blog (we'll auto-detect RSS feed)

Recommended

  • platforms: Which social channels to post to (default: twitter, linkedin, facebook)
  • openaiApiKey / anthropicApiKey / geminiApiKey: At least one AI API key for summarization

Content Settings

  • contentStyle: Tone of voice (professional, casual, witty, informative, promotional)
  • includeEmojis: Add relevant emojis (default: true)
  • includeHashtags: Auto-generate hashtags (default: true)
  • maxHashtags: Maximum hashtags to include (default: 5)
  • customHashtags: Always include these hashtags

Scheduling

  • maxPostsPerRun: Max posts per run to prevent spam (default: 3)
  • delayBetweenPosts: Minutes between posts (default: 5)
  • lookbackDays: Only process posts from last N days (default: 7)

Tracking

  • useUtmTracking: Add UTM parameters (default: true)
  • utmCampaign: Campaign name (default: "blog-syndication")

Posting

  • Either provide platform credentials for direct API posting
  • Or enable useExternalPosters to use our existing poster actors

Example Usage

{

"blogUrl": "https://mybusiness.com/blog",


"platforms": ["twitter", "linkedin", "facebook"],


"openaiApiKey": "sk-...",


"contentStyle": "professional",


"maxPostsPerRun": 5,

}

Scheduling Recommendations

  • Daily Updates: Run once per day if you publish frequently
  • Weekly Check: Run weekly for lower-volume blogs
  • Set lookbackDays to match your posting frequency
