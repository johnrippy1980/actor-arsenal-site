Meta Ad Library Scraper - Facebook & Instagram Ad Intelligence

Scrape the Meta Ad Library for competitor ad research. Extract ad creatives, copy, targeting data, and spend estimates from Facebook and Instagram ads.

Key Features

  • Ad Creative Extraction - Images, videos, and carousels
  • Copy Analysis - Headlines, descriptions, CTAs
  • Multi-Platform - Facebook, Instagram, Messenger, Audience Network
  • Targeting Insights - Demographics, age, gender, location
  • Spend Estimates - Impression ranges and estimated spend
  • Status Filtering - Active vs. inactive ads
  • Camoufox Anti-Detection - Browser fingerprint evasion
  • Firecrawl Option - API-based scraping alternative
  • AI Sentiment Analysis - Analyze ad copy sentiment with 5 AI providers

Quick Start - Real Scraping

{

"searchQuery": "fitness app", "country": "US", "platform": "FACEBOOK", "maxAds": 50, "demoMode": false }

Important: Set demoMode: false to scrape real Meta Ad Library data.

Anti-Detection Options

Camoufox Mode

Camoufox provides browser fingerprint evasion:

  • Hides automation indicators
  • Randomizes browser fingerprints
  • Mimics human browsing patterns
  • Evades common bot detection
Enable with "useCamoufox": true.

Firecrawl Mode

Firecrawl provides API-based scraping:

  • No browser management needed
  • Built-in proxy rotation
  • Automatic retries
  • More consistent results
Enable with "useFirecrawl": true and provide your API key.

Troubleshooting

No ads found

  • Try different search queries
  • Check if the page name is spelled correctly
  • Use Page ID instead of name for better accuracy
  • Enable Camoufox or Firecrawl mode

Getting blocked

  • Enable useCamoufox: true
  • Use Apify proxy configuration
  • Try Firecrawl mode
  • Reduce maxAds per run

Slow scraping

  • Meta Ad Library requires JavaScript rendering
  • Consider using Firecrawl for faster results
  • Reduce maxAds for quicker runs

Limitations

  • Meta Ad Library may require JavaScript rendering
  • Some demographic data requires authentication
  • Rate limits may apply for large scrapes
  • Historical ads may not be available
