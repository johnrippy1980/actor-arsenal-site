Automate posting to Facebook Business Pages! Supports text posts, images, and link shares.

Features

  • Text Posts - Simple status updates
  • Image Posts - Photos with captions
  • Link Shares - Share URLs with custom text
  • Page Selection - Choose which page to post to

Authentication

Two options:

1. Email/Password - Works for accounts without 2FA

2. Cookies - Export cookies from logged-in session (recommended)

Example Input

Text Post

{

"cookies": "[{...exported cookies...}]",


"pageUrl": "https://facebook.com/yourbusinesspage",


"content": "Exciting news! We're launching our new winter menu this weekend. Stop by and try our seasonal specials!",


"postType": "text"


}

Image Post

{

"cookies": "[{...}]",


"pageUrl": "https://facebook.com/yourbusinesspage",


"content": "Check out our beautiful new storefront!",


"imageUrl": "https://example.com/storefront.jpg",


"postType": "image"


}

Link Share

{

"cookies": "[{...}]",


"pageUrl": "https://facebook.com/yourbusinesspage",


"content": "Read our latest blog post about local SEO tips!",


"linkUrl": "https://yourblog.com/local-seo-tips",


"postType": "link"


}

Output

{

"success": true,


"postId": "123456789",


"postUrl": "https://facebook.com/yourbusinesspage/posts/123456789"


}
