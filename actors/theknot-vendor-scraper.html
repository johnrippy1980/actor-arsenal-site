Scrape Wedding Vendors by Location and Category

Planning a wedding means researching dozens of vendors. Photographers, venues, caterers, florists, DJs — all scattered across multiple websites with inconsistent information. The Knot is the largest wedding vendor marketplace, but manually browsing through listings is time-consuming. What if you could extract all vendor data for any location in seconds?

The The Knot Wedding Vendor Scraper extracts:

  • Business name and contact info
  • Ratings and reviews
  • Pricing information
  • Services offered
  • Awards and badges
  • Social media links
  • Gallery images
Perfect for wedding planning apps, vendor directories, and market research.

Complete Vendor Profiles

Each vendor includes:

  • Business name and description
  • Full address and location
  • Phone, email, and website
  • Average rating and review count
  • Price range ($ to $$$$)
  • Services offered
  • Awards (Best of Weddings, Hall of Fame)
  • Social media links
  • Gallery images

Optional Review Scraping

Enable includeReviews: true to extract individual customer reviews with:

  • Author name
  • Rating (1-5 stars)
  • Review date
  • Wedding date
  • Full review text
  • Verified status

Input Parameters

| Parameter | Type | Required | Description |

|-----------|------|----------|-------------|

| location | string | Yes | City and state (e.g., "Austin, TX") |

| categories | array | No | Vendor categories to scrape |

| maxResults | integer | No | Max vendors per category (default: 50) |

| includeReviews | boolean | No | Scrape individual reviews |

| maxReviewsPerVendor | integer | No | Max reviews per vendor (default: 10) |

| demoMode | boolean | No | Use sample data (default: true) |

API Integration

JavaScript/Node.js

import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: 'YOUR_API_TOKEN' });


const run = await client.actor('localhowl/theknot-vendor-scraper').call({


location: 'Austin, TX',


categories: ['wedding-photographers', 'wedding-venues'],


maxResults: 50,


demoMode: false


});


const { items } = await client.dataset(run.defaultDatasetId).listItems();

Limitations

  • Review pagination: Reviews limited to first page unless explicitly requested
  • Geographic coverage: US-focused (The Knot is primarily a US platform)
