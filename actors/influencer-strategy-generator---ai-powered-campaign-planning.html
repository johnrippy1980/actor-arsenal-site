Influencer Strategy Generator - AI-Powered Campaign Planning

AI-powered influencer marketing strategy generator. Creates comprehensive campaign plans, budget allocations, content calendars, outreach templates, and ROI projections based on your goals and analyzed influencers. BYOK for OpenAI/Anthropic.

Features

  • AI-Powered Strategy - GPT-4 or Claude generates tailored campaign strategies
  • Budget Optimization - Smart allocation across influencer tiers and platforms
  • Content Calendar - Week-by-week posting schedule with content themes
  • Outreach Templates - Personalized DM/email templates for influencer outreach
  • ROI Projections - Estimated reach, engagement, and return on investment
  • Influencer Briefs - Creative briefs ready to send to selected influencers
  • Demo Mode - Test with sample strategies (no API key required)

{
  "input": "your input here"

Demo Mode

Set demoMode: true to test with sample data (no charges). When you're ready for real results, set demoMode: false or omit it.

  "demoMode": true,
  ...
}

Input Parameters

{
  "campaignGoal": "brand_awareness",
  "budget": { "amount": 10000, "currency": "USD" },
  "platforms": ["instagram", "tiktok"],
  "influencerTiers": ["micro", "mid"],
  "campaignDuration": "4_weeks",
  "aiProvider": "openai",
  "openaiApiKey": "sk-...",
  "demoMode": false
}

Input Parameters

| Parameter | Type | Default | Description | |-----------|------|---------|-------------| | campaignGoal | string | brand_awareness | Campaign objective (brand_awareness, product_launch, sales_conversion, lead_generation, app_installs, event_promotion, content_creation, community_building, reputation_management) | | budget | object | {amount: 10000, currency: "USD"} | Campaign budget with amount and currency | | targetAudience | object | - | Age range, gender, locations, interests | | brandInfo | object | - | Brand name, industry, values, tone, USPs | | platforms | array | ["instagram", "tiktok"] | Platforms to include in strategy | | campaignDuration | string | 4_weeks | Duration: 1_week, 2_weeks, 4_weeks, 3_months, 6_months, 12_months | | influencerTiers | array | ["micro", "mid"] | Tiers: nano, micro, mid, macro, mega | | contentTypes | array | ["static_post", "reel_video", "story"] | Content types to include | | aiProvider | string | openai | AI provider: openai or anthropic | | openaiApiKey | string | - | Your OpenAI API key (required if using OpenAI) | | anthropicApiKey | string | - | Your Anthropic API key (required if using Claude) | | analyzerDatasetId | string | - | Dataset ID from influencer-analyzer for data-driven strategy | | discoveryDatasetId | string | - | Dataset ID from influencer-discovery | | generateOutreachTemplates | boolean | true | Generate outreach message templates | | generateContentCalendar | boolean | true | Generate posting schedule | | generateBriefs | boolean | true | Generate influencer creative briefs | | demoMode | boolean | true | Run with sample data (no AI calls) | | webhookUrl | string | - | Webhook for results delivery |
