Supported Research Sources

MCP Tools Available

1. get_seo_news

Get latest SEO news and industry trends.

{

"tool": "get_seo_news",


"toolInput": {


"topics": ["google updates", "local seo", "ai search"],


"maxArticles": 20


}


}

2. research_quora

Research industry topics on Quora.

{

"tool": "research_quora",


"toolInput": {


"query": "best marketing automation tools 2025",


"maxResults": 15


}


}

3. get_crunchbase_data

Get company data from Crunchbase.

{

"tool": "get_crunchbase_data",


"toolInput": {


"companyName": "Anthropic",


"includeInvestors": true,


"includeFunding": true


}


}

4. get_clutch_reviews

Get agency reviews from Clutch.

{

"tool": "get_clutch_reviews",


"toolInput": {


"category": "seo-companies",


"location": "United States",


"maxResults": 20


}


}

5. get_g2_reviews

Get software reviews from G2.

{

"tool": "get_g2_reviews",


"toolInput": {


"productName": "HubSpot Marketing Hub",


"maxReviews": 25


}


}

6. get_goodfirms_reviews

Get company reviews from GoodFirms.

{

"tool": "get_goodfirms_reviews",


"toolInput": {


"category": "digital-marketing",


"location": "New York",


"maxResults": 15


}


}

7. analyze_industry_trends

Comprehensive industry trend analysis.

{

"tool": "analyze_industry_trends",


"toolInput": {


"industry": "Digital Marketing",


"timeframe": "6 months",


"includeSentiment": true


}


}

8. get_reddit_discussions

Get Reddit discussions on industry topics.

{

"tool": "get_reddit_discussions",


"toolInput": {


"subreddits": ["marketing", "SEO", "digital_marketing"],


"query": "AI marketing tools",


"maxPosts": 30


}


}

9. research_competitors

Research competitors in an industry.

{

"tool": "research_competitors",


"toolInput": {


"businessName": "Acme Agency",


"industry": "Digital Marketing",


"location": "Chicago",


"maxCompetitors": 10


}


}

10. get_company_contacts

Get company contact information and enrichment.

{

"tool": "get_company_contacts",


"toolInput": {


"companyName": "Example Corp",


"domain": "example.com",


"includeEmails": true


}


}

11. run_market_intelligence

Complete market intelligence report.

{

"tool": "run_market_intelligence",


"toolInput": {


"industry": "SaaS Marketing",


"includeTrends": true,


"includeCompetitors": true,


"includeNews": true


}


}

12. list_tools

Get a list of all available industry research tools.

{

"tool": "list_tools"


}
