Generate premium quality AI images using Google's latest Gemini 3 Pro model. Up to 4K resolution with superior text rendering and photorealistic output.

Why Nanobanana Pro?

  • 2K/4K Resolution: Generate images up to 3840x2160 (4K UHD)
  • Superior Text Rendering: Best-in-class text generation within images
  • Multiple Styles: Photorealistic, cinematic, digital art, anime, and more
  • BYOK Model: Use your own Google AI API key - pay only for what you use
  • Demo Mode: Test the actor without an API key

Getting Your FREE Google AI API Key

1. Go to Google AI Studio

2. Sign in with your Google account

3. Click "Create API Key"

4. Copy your API key and paste it in the actor input

It's completely free to get started! Google provides generous free tier usage.

This actor uses the BYOK (Bring Your Own Key) model:

  • Google Gemini Pro: Billed directly to your Google Cloud account

Pro vs Flash

Choose Pro for marketing materials, print, and professional use.

Choose Flash for quick iterations and budget-conscious projects.

Troubleshooting

API Key Issues

  • Ensure your API key is valid at AI Studio
  • Check you haven't exceeded your quota

Rate Limits

  • Google has rate limits - if you hit them, wait a few minutes
  • Consider upgrading your Google Cloud tier for higher limits

Model Access

  • Gemini 3 Pro requires access to preview features
  • Check Google AI documentation for requirements
